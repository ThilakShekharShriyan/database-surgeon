# Fonts

Public Sans, IBM Plex Sans, and IBM Plex Mono, downloaded from Google Fonts. Licenses are included alongside the files.
Sources: https://github.com/google/fonts/tree/main/ofl/publicsans , https://github.com/google/fonts/tree/main/ofl/ibmplexsans and https://github.com/google/fonts/tree/main/ofl/ibmplexmono

`plex-mono-semibold.woff2` is the Latin subset of IBM Plex Mono SemiBold (OFL, same license file), from Fontsource: https://cdn.jsdelivr.net/fontsource/fonts/ibm-plex-mono@latest/latin-600-normal.woff2
